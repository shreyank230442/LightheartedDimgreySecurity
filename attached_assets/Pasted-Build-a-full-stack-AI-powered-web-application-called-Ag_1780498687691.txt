Build a full-stack AI-powered web application called:

Agentic Visual Incident Investigation System

A Computer Vision, Image Processing, and Generative AI platform that analyzes surveillance videos from multiple cameras, detects suspicious activities, investigates incidents, generates timelines, and produces AI-powered incident reports.

The system should be designed as a final-year Computer Vision / Image Processing project that demonstrates practical usage of Image Processing, Object Detection, Multi-Object Tracking, Event Detection, Agentic AI, and LLM-based reasoning.

PROJECT OBJECTIVE

Traditional CCTV systems require humans to continuously monitor surveillance footage, making it difficult to detect suspicious activities and investigate incidents.

The objective of this project is to build an AI-powered investigation platform that allows users to upload surveillance videos from multiple camera angles and automatically:

Analyze footage
Detect people, bags, and vehicles
Track objects across frames
Identify suspicious activities
Generate incident timelines
Produce investigation reports
Answer questions about incidents through an AI assistant

The project must heavily utilize Image Processing concepts and AI-based reasoning.

EVENT DETECTION ENGINE

Create a rule-based event engine.

Detect:

Condition:

Person remains within same region longer than threshold.

Default:

5 minutes

Crowd Formation

Condition:

More than X people gather in small area.

Running Behavior

Condition:

Person velocity exceeds threshold.

Restricted Area Intrusion

Condition:

Person enters predefined forbidden zone.

Allow user to draw restricted zones on frame.

Abandoned Object

Condition:

Bag remains stationary after owner leaves.

Suspicious Movement

Condition:

Repeated back-and-forth movement.

That version is achievable in a semester and still looks extremely strong on a resume.
